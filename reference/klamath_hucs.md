# Klamath River HUCs

National Hydrography Dataset of HUCs, processed and cleaned. Source:
https://www.sciencebase.gov/catalog/item/5d30c29ae4b01d82ce84aa5e

## Usage

``` r
klamath_hucs
```

## Format

A sf df with 12 rows and 3 columns

- `huc8`: 8 digit HUC code

- `name`: HUC name

- `geometry`: sf polygon
