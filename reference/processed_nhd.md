# NHD Flowlines

National Hydrography Dataset of flowlines, filtered to nhdplusids for
rivers included in the Klamath Basin Science Collaborative.
Source:https://www.sciencebase.gov/catalog/item/5d30c29ae4b01d82ce84aa5e

## Usage

``` r
processed_nhd
```

## Format

A tibble with 4236 rows and 73 columns
