# All Klamath River Lines

National Hydrography Dataset of flowlines, processed and cleaned.
Includes: Blue Creek, Bogus Creek, Camp Creek, Clear Creek, Fall Creek,
Indian Creek, Jenny Creek, Klamath River, Link River, Lost River, Salmon
River, Scotch Creek, Scott River, Shasta River, Shovel Creek, Spencer
Creek, Sprague River, Trinity River, Williamson River, Wood River

## Usage

``` r
all_klamath_rivers_line
```

## Format

A sf df with 20 rows and 2 columns
